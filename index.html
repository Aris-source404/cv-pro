Foire aux questions

Les réponses aux questions les plus courantes.

Mes informations sont-elles enregistrées ?

Elles restent uniquement dans votre navigateur, sur votre appareil. Téléchargez vos données pour les garder ou les modifier plus tard.

Quels formats puis-je télécharger ?

Un PDF d’une page, un fichier HTML du CV, et un fichier de données que vous pouvez recharger dans le site ou envoyer à Claude.

Comment Claude peut-il m’aider ?

Envoyez le fichier de données à Claude avec une demande comme « Fais mon CV en PDF avec ce fichier ». Il peut aussi corriger les fautes et reformuler votre profil.

Le texte du PDF est-il sélectionnable ?

Le PDF téléchargé depuis le site est une image de haute qualité. Pour un PDF avec texte sélectionnable, utilisez le fichier de données avec Claude ou imprimez la version HTML.
